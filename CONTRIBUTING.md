# Contribuindo para COORDIA SMART

## Princípios Não-Negociáveis

1. **Advisory only**: Nenhum agente pode confirmar trabalho concluído.
2. **Proveniência**: Todo dado deve carregar origem e timestamp.
3. **Humano no loop**: Decisão e execução sempre humanas e registradas.
4. **Auditoria**: Trilha imutável de recomendação → revisão → ação.

## Como Contribuir

- Abra issues para discussão de agentes ou requisitos
- PRs devem incluir testes de não-confirmação automática
- Documentação em `/docs`
