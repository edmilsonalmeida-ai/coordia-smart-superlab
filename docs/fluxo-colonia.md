# Fluxo da Colônia

## Conceito

Você entrega a missão. A colônia organiza, pesquisa, debate, executa e verifica.

## Fases

| Fase | O que faz |
|------|-----------|
| Organizar | Identifica escopo e recursos |
| Pesquisar | Analisa eventos e padrões |
| Debater | Agentes discutem prioridades |
| Executar | Processa e gera recomendações |
| Verificar | Valida advisory e proveniência |

## Uso

```python
from colonia.fluxo_missao import Colonia

colonia = Colonia()
resultado = colonia.receber_missao("Descrição da missão", eventos)
```
