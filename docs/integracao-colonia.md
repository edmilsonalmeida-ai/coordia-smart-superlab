# Integração da Colônia CoordIA

## Componentes criados

| Arquivo | Função |
|---------|---------|
| `colonia/guia_colonia.md` | Guia de operação para a colônia |
| `colonia/treinamento.py` | Cenários de treinamento |
| `integracao/conector_github.py` | Prepara issues e comentários no GitHub |

## Como treinar a colônia

```bash
python colonia/treinamento.py
```

## Integração com GitHub

O conector prepara o conteúdo. A criação real da issue usa as ferramentas GitHub já conectadas.

## Próximos conectores possíveis

- Google Drive (planilhas de eventos)
- Gmail (notificações de alta prioridade)
- Automations (rotinas periódicas)

A colônia está treinada e pronta para operar.
