# Modo Leve — COORDIA SMART

Runner contínuo de baixíssimo consumo para demonstração ou monitoramento sintético.

## Como deixar rodando

```bash
python run_leve.py
```

- Processa lotes de 5 eventos sintéticos
- Pausa de 10 segundos entre ciclos
- Grava log append-only
- Zero dependências externas
- Respeita todas as flags de segurança

Ideal para deixar em segundo plano sem impacto.
